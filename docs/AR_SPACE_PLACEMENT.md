# 바닥 없이 공연 배치

4인 공연은 더 이상 눈높이 아래의 바닥 지점만 요구하지 않는다. 벽·탁자·높은 지점도 기존 공간 추적의 특징점 또는 WebXR hit-test로 선택할 수 있다. 화면 중앙과 위·아래·좌우를 탐색한다. 다른 콘텐츠의 명시적인 바닥 제한은 유지한다.

표면을 못 찾았을 때는 **여기에 직접 놓기**를 사용한다. 유효하고 최근의 6DoF 카메라 포즈가 있어야 하며, 사용자가 선택한 추정 거리(0.5~6m, 기본 2m)와 시선에서 월드 좌표를 한 번 계산해 저장한다. 해당 좌표는 카메라의 자식이 아니고, 이후 카메라 이동에 맞춰 다시 계산하지 않는다. 나중에 특징점이 잡혀도 자동으로 다른 곳에 옮기지 않는다.

직접 배치는 건물이나 표면의 위치를 측정한 결과가 아니다. 화면에 **직접 배치 · 공간 고정**으로 구분한다. 공연 높이와 크기를 조절하고, **다시 놓기**로 위치를 바꿀 수 있다. 높이 조절은 배치 앵커를 보존하며 공연 그룹만 수직으로 이동한다. 배치 후 거리 값은 잠가 의도하지 않은 위치 변경을 막는다.

일반 카메라 영상만 있거나 공간 추적이 불안정한 상태에서는 직접 배치도 활성화하지 않는다. 공간 추적 상실 시 공연은 숨김/일시정지되며 사용자가 재개한다. 이 최소 조건까지 없애면 실제 공간에 고정되는 AR로 표시할 수 없기 때문이다.

검사: `node tests/stage-fit.mjs`, `node ar-engine/tests/quartet-unit.mjs`, `node tests/floor-placement-browser.mjs http://localhost:8193`, `node tests/integration-browser.mjs http://localhost:8193`. 눈높이 지점 허용, hit 없는 직접 배치, 추적이 없을 때 배치 차단, 카메라 이동/새 hit 이후 앵커 유지, 높이 조절을 확인한다. 자동 AR 입력은 모의 추적이며 실제 iPhone/Android 현장 검증과 구분한다.
