## 1. 실행

```bash
npm i
npm run dev                      # 개발
npm run build && npx vite preview --port 4173   # 폰 시연용
adb reverse tcp:4173 tcp:4173    # 폰 크롬에서 localhost:4173 (카메라·WebXR 보안 컨텍스트)
```
- 서버 연결: `.env` 에 `VITE_API_URL=http://localhost:8000`. 없으면 고정 예시 데이터로 동작.
- **노트북 npm 오류(미해결)**: node 는 `C:\Program Files\nodejs` 에 있는데 `npm run` 이 실패한 적 있음.
  임시 우회: `node node_modules/vite/bin/vite.js` (dev) / `node node_modules/vite/bin/vite.js build`.

## 3. 코드 구조 · 어디를 고치나

```
src/
  App.jsx            화면 목록 SCREENS (이름 → 컴포넌트)
  store.jsx          상태 · 이동 go(name, houseId) · 회차 · 보관함 · 주소(#) · 진행 초기화
  houses/h1~h3.js    건물마다 파일 하나(이름 · 좌표 · 역할극 · 작품 · 서버 id server) / houses/index.js = 목록·순서
  lib/spots.js       CONFIG(설정값 한곳) + 건물·미션에서 나오는 값(TOTAL_STAMPS 등)
  lib/missions.js    미션 목록 MISSIONS(역할극 · 단서 얻기) — 홈·지도·시트·나의 별자리·06·07 이 이 목록을 돌며 그림
  lib/puzzles.js     별자리 퍼즐 5개 + 회차별 섞기 missionFor(house, round)
  lib/api.js         서버 어댑터(세션 · 회차별 세션 · 쿠폰 · 카페) / 서버 없으면 예시 데이터
  lib/geo.js ar.js artwork3d.js qr.js barcode.js
  ui/                공통 조각: Screen(상단바·하단버튼) · ArFrame(카메라 화면 공통 틀) · chrome(AR 상단) · PauseMenu(보관함) · Camera · MockScene
                     StarPuzzle · Peek(하단 시트) · facade.js(건물 정면 모양) · OldHouse · Eave · Star
  styles/index.js    화면별 CSS 를 순서대로 불러옴(base → pause → home → map → ar → 04~11)
  styles/*.css       base.css 의 :root 토큰만 바꾸면 색 전체 변경
```

| 바꾸고 싶은 것 | 고칠 곳 |
|---|---|
| 회차 수 · 힌트 간격 · 지도 확대 · 반경 · 제한 시간 | `lib/spots.js` `CONFIG` (`rounds` `hintEvery` `mapZoom` `radius` `escapeMinutes`) |
| 별자리 추가 · 실마리 · 힌트 문구 | `lib/puzzles.js` `PUZZLES` |
| 건물 이름 · 좌표 · 역할극 대사 · 작품 | `houses/h1.js` ~ `h3.js` (건물 추가 = 파일 하나 + `houses/index.js` 에 등록) |
| 미션 이름 · 설명 · 08 모아 보기 | `lib/missions.js` `MISSIONS` (미션 추가 = 한 줄 + 화면 하나를 `App.jsx` SCREENS 에) |
| 카메라 화면 공통(카메라 · 상단 · 건너뛰기 · 안내) | `ui/ArFrame.jsx` |
| 건물 정면 그림(자리표시) | `ui/facade.js` |
| 왼쪽 메뉴 항목 | `ui/PauseMenu.jsx` `ITEMS` |
| 쿠폰 사용 가능 카페(이름 · 지도 위치 · 영업시간) | `lib/cafes.js` `CAFES` |
| 색 | `styles/base.css` `:root` |
| 서버 id 짝(h1→a …) | 건물 파일의 `server` |

CSS 규칙: 덮어쓰기 규칙을 파일 끝에 덧붙이지 말고, 그 화면 파일의 원래 규칙을 고칠 것.
