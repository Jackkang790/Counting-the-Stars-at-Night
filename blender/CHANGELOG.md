# 모델별 변경 이력

## starseed_sculpture · 0.1.0 · 2026-10-29

- 작가·작품 미확정 상태의 창작 임시 조형물 **별의 새싹** 제작.
- bpy 생성 스크립트, `.blend` 원본, GLB, 단계별 Cycles 렌더, 매니페스트 작성.
- 곡선 단면을 연속 전달하여 잎·궤도의 연결부 비틀림을 보정.
- 첫 로컬 클립명 `AR_*`를 엔진 계약 초안의 `Emerge`, `Idle` 및 선택 `Disappear`로 정리. 기준점 `ANCHOR_Ground`, GLB -Z 정면으로 통일. 구 이름은 납품 규격이 아님.
- Khronos 규격 검사, GLB 바이너리·재수입·PBR·클립 검사, 렌더 비교 추가.
- Three.js GLTFLoader / AnimationMixer 검사와 독립 로컬 WebGL 뷰어 추가.
- 실제 작품·건물 재현이 아닌 임시 콘텐츠임을 명시. PDF 원본 분석과 실기기 WebXR 검사는 미완료로 구분.

다른 건물·전시·역할극 모델은 아직 제작하지 않았다.
