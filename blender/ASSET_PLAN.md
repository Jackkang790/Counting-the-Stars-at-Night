# 3D 에셋 목록 · 제작 난이도 · 추가 자료

## 근거와 현재 상태

- **직접 확인한 근거:** 사용자 제작 지시(A~E), 대상 건물 3곳, PDF는 기능·화면 와이어프레임이라는 설명.
- **보조 근거:** 읽기 전용으로 확인한 `ar-engine/contracts/README.md`, `asset-spec.md`의 DRAFT. 03/04-A/04-B/04-C/06 화면 매핑은 이 문서의 간접 정보이며 PDF 원본을 직접 분석한 결과가 아니다.
- **미확인:** PDF 원본. 계약 문서가 가리키는 `docs/별헤는밤.proj-와이어프레임.pdf`도 현재 작업 폴더에 없다. 화면별 배치·순서·치수·작품 수·역할극 장면 수는 미확정이다.
- **금지하는 추정:** 와이어프레임을 건축 도면으로 취급하거나, 건물의 층수·창호·지붕·철거 범위·과거 연대를 상상하여 역사적 사실로 제시하지 않는다.
- **첫 납품 범위:** A의 교체 가능한 임시 조형물 1개. B~E는 제작 계획이며 아직 모델을 만들지 않았다.

자료별 촬영/작성일·출처·사용 허락·정확도를 기록한다. 현장 치수는 추정값과 구분한다. 건축 유형·연혁·구조를 이 목록에서 단정하지 않았다.

## GLB 계약 검토

`ar-engine/contracts/asset-spec.md`는 **초안·승인 대기** 상태다. 해당 파일을 수정하거나 최종 계약으로 승인하지 않았다. 사용자 지정 출력 위치 `public/models/`가 우선하며 엔진 폴더에 복사하지 않는다.

| 항목 | 첫 에셋 적용 |
|---|---|
| 포맷·단위 | GLB 2.0, 1 unit=1m, Y-up |
| 정면 | 초안에 맞춰 GLB -Z (Blender +Y) |
| 접지 원점 | `ANCHOR_Ground`, `(0,0,0)`, 지면 Y=0 |
| 등장/대기 | 정확한 클립명 `Emerge` / `Idle` |
| 퇴장 | 추가 선택 클립 `Disappear` (엔진에서 사용 여부 선택) |
| 파일별 매니페스트 | `starseed_sculpture.manifest.json`, 초안 기본 필드에 대응 |
| 전체 에셋 메타데이터 | `asset-manifest.json`, 크기/예산/해시/검증 상세 기록 |
| 압축 | 작은 무텍스처 모델이므로 무압축, 추가 디코더 없음 |
| 텍스처 | 이번 임시 작품은 PBR 단색 4종, 이미지 텍스처 0개. 이미지 사용 시 GLB 내부 포함, 원본은 blender/에 보관 |
| 공통 계약 변경 | 없음. 필드·경로 최종 합의 및 실제 엔진 수용 검사는 별도 |

첫 작품의 내부 목표는 12,000 tris / 4 material / 1.5MB 이하이다. 건물/인물 장면은 실제 화면에 필요한 범위를 확인하여 별도 예산을 정한다. 초안의 150,000 tris / 30 draw calls / 15MB는 상한 제안이며 실기기 합격을 뜻하지 않는다.

## 남은 작업

1. PDF 파일 경로 또는 원본을 확보하여 화면별 에셋 목록·필수 클립·의존성·수량을 대조한다.
2. 건물별 자료를 받아 현재 모습과 고증 근거의 충족 여부를 기록한다.
3. 작가/작품, 실제 배치 위치·방향, 전시 목록, 대본을 확정한다.
4. 공통 계약 초안의 최종 합의 및 Claude Code 엔진에 연결한 검사를 수행한다.
5. Android Chrome 실기기 WebXR에서 스케일·시인성·발열·FPS·전환을 확인한다.

PDF 직접 분석·실제 건물 모델링·역사 고증·모바일 현장 검증은 완료로 표시하지 않는다.
