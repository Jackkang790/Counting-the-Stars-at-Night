# 공간형 실사 AR 공연자 검증 기록

브랜치: `feat/live-action-ar-musical-mvp`. 이 기록과 [새 정적 시연 ZIP](./demo-root.zip)은 이전 `musical-mvp` 산출물에 공간형 공연자·3D 시퀀스 로더를 추가한 버전이다. 공개 배포는 하지 않았다.

실사 영상은 건물 앵커 아래의 고정된 Three.js 메시다. 같은 `PerformerSlot`에 시간별 비평면 GLB 프레임을 불러오는 로더를 구현했고 30초 공연의 음원 시계·등장/퇴장·무대 효과를 공유한다. **실제 인물의 볼류메트릭 촬영본은 아직 없으며 실제 iPhone·Android AR 검증도 수행하지 않았다.**

| 오인 방지 | 비인물 3D 도형은 실사 공연 버튼으로 시작 불가. 진단의 기기·실사 볼류메트릭 검증값은 false |

## 실행과 미완료 항목

ZIP 내용을 HTTPS 호스팅의 **루트**에 배치한다. 기존 화면에서 새 공연으로 진입하거나 `?musical=1`을 연다. 현재 개발 서버는 `https://172.16.42.83:5187/?musical=1`이며 같은 Wi-Fi·신뢰된 HTTPS가 필요하고 IP는 달라질 수 있다.

스마트폰에서는 **실사 샘플 2명 불러오기 → AR 카메라 → 정합 확정 → 공연 시작** 순서다. 표적 전체가 충분히 크게 보여야 한다. 좌우 이동·접근·추적 상실·재인식·음원 동기·가림·사진·30초 재시작을 실제 벽 앞에서 확인하고 진단을 저장해야 한다. 개발 미리보기는 실제 AR 검증으로 기록하지 않는다.

남은 항목은 실제 인물 볼류메트릭 촬영본, 지역 공연자의 최종 안무·음원, 벽의 실측, 실제 iPhone Safari·Android Chrome의 이동/가림/동기/발열 검증이다. 기본 저대비 표적은 작게 보일 때 인식이 실패할 수 있다. 공통 경로는 표적이 보이는 동안의 이미지 포즈 추적이며 표적 밖 영속 SLAM이 아니다. 1단계 영상은 얇은 평면이고, 3D 로더는 배우당 48MiB로 제한한 사전 로드 방식이다.
