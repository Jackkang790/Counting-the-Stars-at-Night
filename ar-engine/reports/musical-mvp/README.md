# 실사 AR 뮤지컬 MVP 검증 결과

후속 공간형 공연자·동적 3D 로더 구현과 최신 시연 ZIP은 [spatial-volume 검증 기록](../spatial-volume/README.md)에 있다. 이 폴더는 최초 영상 MVP 검증 시점의 산출물이다.

작업 브랜치: `feat/live-action-ar-musical-mvp`.

사진 기반 무대와 분리된 가림 모델, 두 실사 영상 렌더러, 30초 음원 기준 타임라인, 조명·파티클, 수동 정합·저장, 다시 보기와 사진 합성을 구현했다. 기존 엔진·모델·설정의 보호 검사가 통과했다. **새 공연의 실제 iPhone·Android 현장 검증은 아직 수행하지 않았다.** ADB에 연결된 기기도 없었다.

## 실행 및 산출물

- [실행·촬영·실기기 검증 안내](../../MUSICAL-MVP.md)
- [시연용 정적 배포 ZIP](./demo-root.zip): HTTPS 호스팅의 루트에 압축 내용을 배치한다. `index.html`·기존 모델·두 실사 샘플·추적 코드·표적을 포함한다. 공개 호스팅에는 배포하지 않았다.
- [공연 데이터](../../musical-assets/show.json)
- [실사 샘플 출처와 사용 조건](../../musical-assets/MEDIA-CREDITS.md)

로컬 검증용 시연 서버는 `https://172.16.42.83:5187/?musical=1`이다. 같은 Wi-Fi와 신뢰된 HTTPS 연결이 필요하다. **실사 샘플 배우 2명 불러오기 → AR 카메라 시작 → 정합 확정 → 공연 시작** 순서로 실행한다.

## 통과한 검사

| 검사 | 결과와 범위 |
| --- | --- |
| 타입 검사 및 표준 빌드 | 통과, 루트·서브경로 모두 |
| 기존 파일 보호 | 38개 파일 검사. HTML의 `main.ts → bootstrap.ts` 진입점 한 줄을 제외하면 원본과 동일 |
| 별의 새싹 | 기존 GLB와 Emerge·Idle·Disappear 통과 |
| 외벽 | 기존 레이어 5종·기준점 11개·6m/3.6m 규격 통과 |
| 30초 공연 | 실사 샘플 재생·반복·일시정지·다시 보기 통과 |
| 영상 | 비인물 패턴 2개와 라이선스가 확인된 실사 영상 2개의 디코딩·알파 렌더링 통과 |
| 이미지 추적 | 합성 카메라 입력에서 실제 MindAR 인식기 실행, 실사 영상 동시 렌더링·표적 상실 시 숨김과 정지·재인식 후 자동 재개 방지 통과 |
| 사진 | 위 합성 카메라 입력과 실사 영상의 PNG 합성·다운로드 통과 |
| 기존 iPhone 웹 경로 | iPhone UA에서 원래 GLB→USDZ와 `rel=ar` 링크 생성 통과. 네이티브 Quick Look은 실행하지 않음 |
| 최종 라우팅 | 루트·`/Counting-the-Stars-at-Night/` 에셋 및 영상 로드 통과. 개발 미리보기의 진단은 AR 추적 성공으로 표시하지 않음 |

[브라우저 통합 결과](./browser-report.json), [최종 경로·진단 결과](./route-report.json), [전체 검사 및 소스 SHA-256](./verification.json).

브라우저 검사는 Windows의 headless Chrome과 ANGLE SwiftShader를 사용했다. FPS는 이 소프트웨어 렌더링 환경의 관찰값이며 스마트폰 성능 수치가 아니다. 작은 저대비 표적은 인식하지 못해 카메라 구도를 조정했다. 실제 패널의 조명·시야각·기기에서 인식률과 포즈 안정성을 다시 확인해야 한다.

## 남은 현장 검증

1. 실제 iPhone Safari·갤럭시 Chrome에서 권한·추적·2개 영상·음원·재시작을 확인한다.
2. 실측 너비·깊이와 프레임 위치를 맞추고 이동 중 배우와 실물의 상대 위치를 확인한다.
3. 폰의 디코딩·발열·FPS·시작/중간/재개 후 음원 동기를 계측한다.
4. 실제 공연자의 완전한 전신·깨끗한 알파·음악에 맞춘 촬영본으로 교체한다. 제공한 스톡은 기술 시연용이며 완성된 지역 문화 공연이 아니다.

공통 경로는 표적이 보이는 동안의 이미지 포즈 추적이며 영속적인 마커리스 SLAM이 아니다. 기존 iPhone Quick Look 기능은 그대로 보존하고, 새 실시간 영상은 별도 이미지 추적 경로에서 실행한다.
