# Android Chrome 실기기 테스트 가이드 (처음 하는 사람용)

> 목적: 별의 새싹 AR·건물 정합 AR을 **실제 스마트폰**에서 확인.
> 이 문서만 순서대로 따라 하면 됩니다. **실기기 통과 전에는 어떤 항목도 "완료"가 아닙니다.**

## 0. 준비물
- **Android 스마트폰**(ARCore 지원 기기 대부분). 아이폰은 WebXR AR 미지원 — 화면이 안내함.
- 스마트폰 **Chrome 최신 버전**.
- 스마트폰에 **"Google Play 서비스(AR)"**(ARCore) 설치/업데이트(Play 스토어에서 검색).
- PC(이 저장소가 있는 Windows).
- **방법 A**(Wi-Fi): 폰과 PC가 같은 공유기 네트워크. / **방법 B**(USB): USB 케이블. → 둘 중 하나.

## 1. 개발 서버 실행 (PC)

**작업 디렉터리(정확히 이 폴더):**
```
Z:\sjb\Counting-the-Stars-at-Night\ar-engine
```

**처음 한 번만** 패키지 설치:
```powershell
cd Z:\sjb\Counting-the-Stars-at-Night\ar-engine
npm install
```

서버 실행은 접속 방법에 따라 **둘 중 하나**:

- **방법 A — Wi-Fi(HTTPS):**
  ```powershell
  cd Z:\sjb\Counting-the-Stars-at-Night\ar-engine
  npm run dev
  ```
- **방법 B — USB 포트포워딩(HTTP, 인증서 경고 없음):**
  ```powershell
  cd Z:\sjb\Counting-the-Stars-at-Night\ar-engine
  $env:AR_HTTP='1'; npm run dev
  ```

> 종료는 터미널에서 `Ctrl + C`. 포트는 **5173** 고정.

## 3. 방법 A — 같은 Wi-Fi + HTTPS
1. 폰과 PC를 **같은 공유기**에 연결.
2. PC에서 `npm run dev` 실행(위 1번).
3. 폰 Chrome에서 **`https://172.16.42.83:5173/`** 접속.
4. "연결이 비공개로 설정되어 있지 않습니다" 경고 → **고급 → (안전하지 않음) 계속 진행**.
   (자체 서명 인증서라 뜨는 정상 경고입니다.)
5. 페이지가 열리고 상단에 **"● AR 지원"** 이 보이면 성공 → 5번 섹션으로.
   - 연결이 안 되면: 폰·PC가 같은 대역인지, 방화벽(5173)인지 확인. 안 되면 **방법 B**.

---

## 4. 방법 B — USB 포트포워딩 + HTTP (인증서 문제 없음, 권장)
> 폰의 `localhost`는 HTTP여도 보안 컨텍스트로 인정되어 **WebXR이 동작**하고 **인증서 경고가 없습니다.**

1. PC에서 **HTTP 모드로** 서버 실행: `$env:AR_HTTP='1'; npm run dev` (위 1번 방법 B).
2. 폰에서 **개발자 옵션** 켜기: 설정 → 휴대전화 정보 → **빌드번호를 7번 탭**.
3. 폰 설정 → **개발자 옵션 → USB 디버깅 켜기**.
4. USB 케이블로 폰 ↔ PC 연결. 폰에 "USB 디버깅을 허용하시겠습니까?" → **허용**.
5. PC **Chrome** 주소창에 `chrome://inspect/#devices` 입력.
   - **"Discover USB devices"** 체크 → 잠시 후 아래에 폰 기기명이 보이면 OK.
6. 같은 화면의 **"Port forwarding…"** 버튼 클릭 → 한 줄 추가:
   - Port: **`5173`**
   - IP address and port: **`localhost:5173`**
   - 아래 **"Enable port forwarding"** 체크 → **Done**.
7. 폰 Chrome에서 **`http://localhost:5173/`** 접속 → 경고 없이 열림.
8. 상단에 **"● AR 지원"** 확인 → 5번 섹션으로.

## 5. 별의 새싹 AR 실행 (emergent-artwork)
화면 상단 선택 상자에서:
- 건물: 아무거나(예: 관사 16호) · 스팟: spot-01
- **체험: "빈 땅 작품 (emergent-artwork)"**
- 임시 모델: **"Codex GLB 우선"**

1. **[AR 시작]** → 카메라 권한 **허용**.
2. 바닥(무늬 있는 바닥 권장)을 천천히 비추면 **흰 링(레티클)** 표시.
3. 바닥을 **탭** → 작품 배치 → **땅에서 솟아오름(Emerge) → 대기(Idle)**.
4. 작품을 **탭** → 강조 펄스(상호작용).
5. **[작품 퇴장(Disappear)]** → 사라짐 → 다시 바닥 탭 시 재등장.
6. **[AR 종료]**.

**핵심 확인:** 로그에 `✓ ready — Codex GLB 로드됨 … clips=[Emerge, Idle, Disappear]` (임시 모델 아님).

## 6. 건물 정합 AR 실행 (alignment)
선택 상자에서 **체험: "외벽 정합 시험 (alignment)"** 선택 후:

1. **[AR 시작]** → 카메라 허용.
2. 바닥을 비춰 링이 보이면 **탭** → 외벽 시험물 배치.
3. 하단 **정합 보정 패널** 사용:
   - **레이어 체크박스**: 기준 외벽 / 격자 / 기준 마커 / 반투명 오버레이 / 기준점 → 각각 켜고 끄기.
   - **위치**(X/Y/Z ±0.05m) · **회전**(Yaw/Pit/Rol ±1°) · **크기**(작게/크게 ±2%) 버튼으로 수동 보정.
   - **저장** → 현재 보정값 저장 · **불러오기** → 저장값 적용 · **초기화** → 배치 직후로 복귀.
4. **[AR 종료]**.

**핵심 확인:** 레이어 토글이 즉시 반영되는지, 보정 버튼으로 모델이 움직이는지, 저장 후 재실행→불러오기로 복원되는지.
> 실제 관사 16호와의 정합은 **현장 자료·실기기 검증 전까지 완료 아님**(지금은 합성 시험물).
